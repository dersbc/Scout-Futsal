# Scout Futsal

Versão V2.2 PWA, criada a partir da V2.1 estável.

Objetivo desta etapa: permitir publicação HTTPS, instalação com ícone e funcionamento offline, sem alterar a metodologia ou o fluxo operacional do Scout.

## Arquivos
- `index.html` — aplicação Scout Futsal.
- `manifest.webmanifest` — configuração de instalação do app.
- `sw.js` — suporte offline/cache do aplicativo.
- `icons/` — ícones da instalação.

## Dados
Os dados de partidas, atletas e histórico continuam armazenados localmente no navegador/dispositivo. Não publicar arquivos de backup `.json`, dados reais de atletas ou informações privadas neste repositório público.
